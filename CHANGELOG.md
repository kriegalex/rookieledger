# RookieLedger v0.8.2

- The sync app for Windows finds the game wherever you installed it: it looks for the `World of Warcraft` folder
  on every disk of the computer, not only in the usual places. If it still does not find it, the window has a
  *Choose the game folder…* button.
- A new line in the window sets how often the app checks for new data: every minute, or every 5 or 10 minutes.
- Nothing changes in the addon: this version is about the sync app.
- Until version 1.0, RookieLedger is a beta: things can still change between versions.

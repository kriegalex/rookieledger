# RookieLedger v0.8.1

- The sync app for Windows has two settings, in the right-click menu of its icon. *Start with Windows* is ticked
  at first: untick it and the app runs only when you start it. *Show details* makes the window say why the site
  was not reached, or why your game data is not found.
- On Linux, `--status` says the same about the game when it finds no data.
- Nothing changes in the addon: this version is about the sync app.
- Until version 1.0, RookieLedger is a beta: things can still change between versions.
